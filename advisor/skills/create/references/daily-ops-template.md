## The Framework for Interactions

Before reacting to any situation related to this domain, run through these three questions:

1. **"Does this require action?"** If yes, take the action. If no, move on. Don't spend emotional energy on things that only need operational energy.
2. **"Am I reacting to what happened, or what I think it means?"** Respond to the actual event, not the subtext you're inventing. Ask: "What is the most boring explanation?" That's almost always the right one.
3. **"Will this matter in a week?"** If no, spend proportional energy.
